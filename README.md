# Overlay Console 🚀

An interactive real-time overlay console web application ready for deployment on **GitHub Pages**.

## 🌟 Features
- Lightweight standalone HTML/CSS/JS architecture
- Live log stream simulator
- Tailored for GitHub Pages hosting

## 🛠️ Quick Setup
1. Clone repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/overlay-console.git
   ```
2. Open `index.html` in your browser or enable **GitHub Pages** under repository settings.
